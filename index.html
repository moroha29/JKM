Product · AI · Geospatial

HomeOS

Making one of life’s biggest decisions feel less like guesswork.

The brief

Turn fragmented housing data into a decision people can understand and defend.

5
specialist AI agents
3
property modes
1
traceable evidence path

The decisive move

We put deterministic geospatial services underneath the AI. Agents can choose tools and explain the shortlist, but every cited number still traces back to reproducible PostGIS-backed evidence.

Read the build story

Challenge

Property search shows inventory. Buyers need judgement.

Price, lease, schools, transit, household needs, and future risk sit across different sources. Comparing them manually is slow and hard to explain.

Approach

One map, two ways to think.

Explore mode gives hands-on control. HomeOS turns a natural-language household brief into a live multi-agent investigation, then lets the buyer question and refine the result.

Outcome

A shortlist with reasons, not a black-box score.

Typed agent outputs, streaming progress, live resale data, commute analysis, accessibility scoring, and a provider-agnostic model layer make the product both ambitious and testable.

02 / 03

Brand · Web · Content system

Moof

Giving a small matcha bar a digital presence with room to become itself.

Matcha & hojicha · Shenton Way

The brief

Build a distinctive hospitality site without locking a young brand into one expression.

5
design directions built
1
shared publishing model
0
runtime framework overhead

The decisive move

Instead of polishing one safe concept, we built multiple complete directions against the same real content. That made taste discussable—and made the final system flexible enough to evolve without rebuilding the brand from scratch.

Read the build story

Challenge

New brands need conviction and optionality at the same time.

The experience had to feel considered, local, and tactile while keeping menus, imagery, hours, and story content straightforward to update.

Approach

Editorial restraint over café clichés.

Large type, real counter photography, warm negative space, and a deliberately small information architecture let the atmosphere do the selling.

Outcome

A fast static experience backed by structured content.

Five Astro concepts explore distinct art directions while sharing the operational thinking that later powers visual publishing through Website Manager.

03 / 03

Platform · Workflow · Operations

Website Manager

Making publishing feel safe enough to hand over—and powerful enough to keep.

The brief

Let non-developers update live sites without turning deployment into a leap of faith.

5
managed site directions
2×
before / after review
24/7
resumable publish queue

The decisive move

We treated publishing as a durable, reviewable job—not a button that fires and hopes. Every change maps to real content, every release shows its exact before-and-after, and every deployment can resume after interruption.

Read the build story

Challenge

Visual editing is easy. Trustworthy publishing is not.

Repeated text, simultaneous editors, scheduled releases, image ownership, and failed deployments all create ways for a “simple CMS” to quietly publish the wrong thing.

Approach

Make state and consequence visible.

Sandboxed previews bind rendered blocks to canonical JSON paths. Immutable drafts, field-level merges, role-based access, and GitHub pull requests protect the path to production.

Outcome

A compact operations layer with serious foundations.

Encrypted recovery, audit history, notification linking, deployment health, retries, and production-ready OVH orchestration live behind an interface built for everyday use.
